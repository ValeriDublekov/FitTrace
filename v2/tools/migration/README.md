# Ръководство за миграция на данни (Firestore -> PostgreSQL)

Този помощен инструмент ви позволява да прехвърлите съществуващите си тренировки и персонализирани упражнения от Google Cloud Firestore в новата релационна PostgreSQL база данни на домашния сървър.

---

## Как работи инструментът

1. **Експорт:** Извлича данните от Firestore (като запазва дати, тежести, серии и бележки).
2. **Трансформация:** `migrate.ts` генерира нови уникални UUID (GUID) за релационните таблици и изгражда пълно релационно дърво:
   - `users`
   - `exercises`
   - `workouts`
   - `workout_exercises`
   - `exercise_sets`
3. **Запис (SQL Transaction):** Генерира се файлът `pg-seed.sql` с `BEGIN TRANSACTION` и `COMMIT`, който се изпълнява в PostgreSQL на домашния сървър.

---

## Стъпки за изпълнение

### 1. Подготовка на експортния файл
Ако имате експортиран JSON от Firestore, запишете го като `firestore-export.json` в тази папка със следната структура:
```json
{
  "exercises": [ ... ],
  "workouts": [ ... ]
}
```

### 2. Генериране на SQL скрипта за PostgreSQL
В конзолата стартирайте:
```bash
npx tsx v2/tools/migration/migrate.ts
```
Скриптът ще генерира готов `pg-seed.sql` файл.

### 3. Изпълнение на скрипта в PostgreSQL на домашния сървър
Ако сървърът работи с Docker Compose:
```bash
# Копирайте SQL файла в контейнера и го изпълнете
docker compose exec -T postgres psql -U fittrace -d fittrace < pg-seed.sql
```

Всички тренировки ще бъдат налични веднага във v2 с перфектна релационна консистентност.
